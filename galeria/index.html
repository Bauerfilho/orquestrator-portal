Laboratório de possibilidades

Maquetes, três estados cada

Cada cartão abre um stand: o app inteiro, funcionando com dados fictícios, com os três estados à mão, a ficha técnica e o código para levar embora.

  1. 1
    Abra o standO app roda inteiro, em tela ampla ou de celular, com dados de mentira.
  2. 2
    Percorra os três estadosBotões no topo ou teclas 1, 2 e 3. A ficha diz paleta, peças e direção.
  3. 3
    Leve o código"Código" entrega o app sem o stand: um HTML único, pronto para virar produto.

Dados fictícios · nenhuma operação real · cada maquete é um arquivo HTML único, sem rede e sem fontes externas. Referências de mercado: desenho original na mesma categoria, sem código, marca ou imagem dos produtos citados.
